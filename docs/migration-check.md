# クリーン移行の検証

完成済みの公開候補から、現行の追跡ファイルを取り出した。以前のコミット、プルリクエスト、Actionsのログ・キャッシュ・成果物、Secretsは初回コミットに含めない。

チャンネル台帳は70件。取得・表示の対象はYouTube 59件。Twitch 11件は台帳に保持し、取得・表示を凍結している。公開前に npm test と npm run build を実行する。ブラウザテストはルートと、GitHub Actionsの実行先リポジトリ名に対応した公開パスを確認する。

配備はPublicリポジトリの main で、PUBLISH_PAGES が true かつ取得結果が公開可能な場合に実行する。初期配信JSONには認証情報を含めない。定期実行を切り替える前に、新リポジトリのSecretsを設定し、実取得と公開先の動作を確認する。
