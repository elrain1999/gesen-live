# ゲーセン対戦台LIVE
レトロ格闘ゲームの承認済みYouTube 59チャンネルについて、ライブ・配信予定・アーカイブを表示します。ゲームと配信状態を複数選択できます。Twitch 11件は登録情報とアダプターを保持し、取得・表示・認証を停止しています。

## ローカルで確認
Node.js 22で `npm run build`、`npm test` を実行し、`python3 -m http.server 8000 --directory dist` で開きます。PlaywrightとChromiumがある環境では `npm run test:browser` でスマートフォン幅を検証できます。

## 取得と公開
Actionsの取得は日本時間0〜16時台は毎時7分、17〜23時台は各時7分から10分ごと、および手動実行に対応します。ブラウザは同じサイトの静的な配信JSONを読み込みます。更新に失敗した場合は取得済みの有効なデータを期限内で表示します。[設定手順](docs/api-setup.md)

## チャンネル台帳
本番チャンネル登録には表示・取得に使う情報を収録しています。ビルドは登録ファイルのSHA-256、サービス別件数、YouTube IDの重複を確認します。実API取得とテスト用の模擬データは分けて扱います。
